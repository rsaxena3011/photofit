A quick guide to PhotoFit

Three steps, and you're done

  1. Add photos. Choose, drop, or paste JPG, PNG, or still WebP images.
  2. Choose your output. Set a file format, size limit, and dimensions. Crop or rotate individual photos if needed.
  3. Process and save. Check the before-and-after preview. Save one image or all finished images as a ZIP.

Need an exact size, like 600 × 600?

Crop to 1:1 square, set Image dimensions → Set width → 600, enable enlarging if your crop is smaller, and turn off Allow smaller dimensions to meet the limit. PhotoFit reports when the chosen size cannot meet a file-size limit.

How file-size limits work

PhotoFit checks the actual encoded file size. For JPG and WebP it tries different quality settings. PNG uses lossless encoding, so reducing its file size may require smaller dimensions. With the smaller-dimensions option enabled, PhotoFit can shrink an image further. If a target cannot be met, the output is clearly marked Over limit.

Limits use decimal KB: 100 KB means 100,000 bytes. Extra upload-site requirements, such as subject framing or file format, still apply.

Your originals and privacy

PhotoFit creates new copies and never changes the original files. It runs offline from this HTML file and makes no network requests. Photos and results stay in this tab's memory; save your results before closing or reloading.

JPG fills transparent areas with the chosen background color. PNG and WebP keep transparency where the browser encoder supports it.

Supported images and practical limits

Use a modern browser. Input is limited to 50 still JPG, PNG, or WebP files per batch, 50 MB per file and 64 megapixels per image. GIF, HEIC, SVG, PDF, and animated PNG/WebP are not supported. Exports are capped at 8,192 pixels per side and 16 megapixels; large originals may be reduced. A combined ZIP is limited to 250 MB; larger batches can be saved individually.

WebP export is enabled only if this browser supports it. Re-encoding changes file metadata and can change color appearance; retain your originals for archival use. This is a screen/pixel-size tool, not a print-DPI editor.

Editing and downloads

In Crop, drag the selection or its corner handles. The numeric fields also work with the keyboard. Crops and rotation belong to each image; output settings apply to the whole batch. Changed settings clear old results, so process again before saving.

If a download preview blocks editing or saving, extract the ZIP and open index.html directly in your browser. Download locations are controlled by your browser.
